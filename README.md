# Lexfix

Lexfix is a comprehensive platform designed to support individuals with learning disabilities, specifically focusing on Dyslexia and ADHD. It brings together various tools and modules to create an inclusive learning environment.

## Project Structure

The project is organized into several key directories:

- **`frontend`**: The main React application for the user interface.
- **`backend`**: The Node.js/Express server handling core functionalities.
- **`adhd_learning_lexfix`**: A dedicated module for ADHD-related learning features.

## Getting Started

To get the project up and running on your local machine, follow these steps:

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/kanishka1259/Lexfix.git
    cd Lexfix
    ```

2.  **Install all dependencies**:
    ```bash
    npm run install:all
    ```
    *This command installs dependencies for the root, backend, frontend, and sub-modules.*

3.  **Start the development servers**:
    ```bash
    npm run dev
    ```
    *This will concurrently start all necessary services.*
