# Infrastructure Epic (04-infrastructure)

This folder contains the work for the Infrastructure Epic.

## Workflow Rules

All contributors to this epic must adhere to the following rules:

### 1. Workspace Isolation
-   **Assigned Folder:** `04-infrastructure`
-   **Restriction:** **DO NOT** modify files outside this folder without explicit permission.
-   **Root Configs:** **DO NOT** change root `.github` workflows.
-   **Testing:** Run `npm test` inside this folder to verify changes.

### 2. Pull Requests (Frequency is Key)
-   **Draft PRs:** Open a PR as soon as you have a basic implementation (Draft Mode).
-   **Target:** 3-5 PRs per Epic.
-   **Description:** Use the PR template. Link to the Issue (e.g., `Closes #123`).
-   **Review:** Request a review from the Repo Owner.

### 3. Issues
-   **Pre-requisite:** Create an Issue for every task **BEFORE** you start coding.
-   **Closure:** Close the Issue via PR.
